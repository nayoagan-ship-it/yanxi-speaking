# 言习 · 中英文口语练习

**在线使用：[点击打开言习 · 中英文口语练习](https://yanxi-speaking-practice.nayoagan.chatgpt.site)**

手机或电脑浏览器直接打开即可使用。首次录音时，请允许浏览器使用麦克风。

关于中英文口语练习的网页，初衷是主播自己说话没有逻辑，梦到什么说什么，想要说话条理一点，顺便提升一下英语口语，毕竟期末还有口语测试。

主页做的有点简陋但胜在方便直接，同时支持存档与回档，可以反复让自己的玉音环绕（坏笑）

总之，希望各位能笑纳，玩的开心就好。
